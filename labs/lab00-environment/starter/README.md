# Lab0 starter

这个 Lab 没有代码 TODO。你的任务是照着 [`../README.md`](../README.md) 和
[`docs/environment.md`](../../../docs/environment.md) 把环境装起来。

装完之后，运行:

```bash
bash ../../../scripts/check-env.sh
```

看到"环境检查通过"再进入 Lab1。

如果你想先看看"装对之后大概是什么效果"，可以看 [`../solution/smoke-test.sh`](../solution/smoke-test.sh)，
里面是一个不依赖任何 Lab 代码、纯粹验证 QEMU + 交叉编译器基本可用的最小示例。
